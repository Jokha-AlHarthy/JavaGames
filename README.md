# 🎮 Java Games - Tic-Tac-Toe

A classic desktop **Tic-Tac-Toe** game built using Java Swing featuring two distinct play modes.

---

## 🚀 Game Modes

1. **Player vs. Player (2 Players)**: Play locally with a friend on the same device.
2. **Player vs. Smart Bot (Unbeatable AI)**: Test your skills against an AI opponent (**Player X vs. Bot O**) powered by the **Minimax Algorithm**.

---

## ✨ Features

* **Dual Gameplay Modes**: Choose between playing locally against another player or against an AI.
* **Unbeatable AI**: The bot uses the **Minimax Decision Algorithm** to calculate optimal moves (you can only draw or lose!).
* **Clean Swing UI**: Simple, responsive interface with a visual delay timer for the bot's turn to simulate thinking time.
* **Game Management**: Dynamic status tracking (win, loss, draw detection) and an instant restart button.

---

## 🛠️ Requirements & Tech Stack

* **Language**: Core Java (Java 8 or higher)
* **GUI Framework**: Swing (`javax.swing`)
* **Core Concepts**: 2D Arrays, Event Handling (`ActionListener`), Recursion (Minimax Algorithm)
